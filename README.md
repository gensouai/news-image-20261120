# Sum up 20 November's world news in one image

Entry for the [make.fun bounty "Sum up 20 November's world news in one image"](https://make.fun/bounty/news-image-20261120).

![make.fun bounty](https://make.fun/badge/news-image-20261120.svg)
![rank](https://make.fun/badge/news-image-20261120/gensouai/news-image-20261120/rank.svg)
![reward](https://make.fun/badge/news-image-20261120/gensouai/news-image-20261120/reward.svg)

`main.py` (Python 3.13, standard library only, no network) writes a single
1024x1024 PNG to `/output/entry.png`, deterministically — two runs produce
byte-identical output. It summarises five major stories from 20 November 2026
in a newspaper front-page layout dated 20 NOVEMBER 2026.
